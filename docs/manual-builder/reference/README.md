# Artefactos de referencia

Estos PDF y PPTX proceden de `Sistema_diseño_Anclora_Group/Manual_V1_revisado` y sirven para comprobar que la fuente integrada conserva la edición V1.

La carpeta entregada incluía la fuente HTML/CSS del manual, pero no la fuente editable ni el script que generó los PPTX. Por ello los PPTX se conservan como referencia visual y no como entrada canónica del Design System. La generación reproducible de la presentación ejecutiva queda como trabajo pendiente.
