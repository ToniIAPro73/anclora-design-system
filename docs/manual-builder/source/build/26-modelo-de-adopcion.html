Dependencia y consumo

Fija el SHA Git inmutable de V1 (paquete privado en GitHub).
Prohibido: development, main, latest o una rama flotante.
Entrada agregada: @anclora/design-system/system.css.
Exportaciones granulares públicas si el empaquetador lo exige, registrando el puente.
Importaciones profundas o internas: no admitidas.

Alcance del perfil

1
data-profile en la raíz de la aplicación o de la plantilla de ruta.
2
Un repositorio puede tener varias raíces con perfiles distintos.
3
Nunca se anidan declaraciones de perfil que compitan.
4
data-theme es independiente; un producto de un solo tema puede omitir el selector.

Reutilizar cuando…

Existe un componente o patrón que resuelve la necesidad.
La experiencia puede ser coherente con lo ya definido.
Se reduce mantenimiento y se acelera la entrega.

Extender cuando…

La necesidad no está cubierta y hay un punto de extensión sancionado.
Se trata de textos, acento de marca o composición propia.
Si se repite en productos independientes → auditoría y RFC, no una bifurcación local.

Qué debe recordar un equipo

El sistema existe para acelerar y unificar, no para limitar.
Una superficie coherente por ola de migración.
El porcentaje de adopción no mide la madurez del sistema.
Registra puentes, excepciones y decisiones.
