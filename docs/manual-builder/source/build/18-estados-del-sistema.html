Estados del sistema
y asincronía

Ocho piezas separadas comunican progreso, resultado y recuperación. No existe un «megacomponente» de estados.

Piezas canónicas

componentStatus · STABLE
1. Aviso alert
Tienes cambios sin guardar.

Persistente; riesgos o información importante.

2. Notificación breve toast
Guardado correctamente

Temporal; confirma acciones no críticas.

3. Estado vacío emptyState
Aún no hay elementos

Primer uso, sin resultados, filtrado o sin permiso.

4. Estado de error errorState
No se pudo cargar · Reintentar

Fallo de página con acción de recuperación.

5. Carga loading
Cargando…

Duración desconocida y breve.

6. Progreso progress
Subiendo archivo… 60 %

Sólo con un valor numérico fiable.

7. Procesamiento processing
● ● ●
Analizando 1.248 registros

Operación con contexto de actividad.

8. Esqueleto skeleton

Marcador estructural del contenido.
